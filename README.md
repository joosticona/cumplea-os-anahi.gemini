# 🎂 Web Interactiva de Cumpleaños para Anahí (Astro + HTML + SCSS/CSS + JS)

Este proyecto incluye tanto la estructura completa en **Astro** como una versión lista para abrir o subir directamente a **Netlify**.

## Estructura del Proyecto
- `src/pages/index.astro`: Página principal en Astro.
- `src/layouts/Layout.astro`: Plantilla base HTML.
- `src/styles/main.scss` y `src/styles/styles.css`: Hojas de estilo con combinación equilibrada en **Azul, Morado y Lila** (en SASS/SCSS y CSS).
- `src/scripts/app.js`: Lógica interactiva en JavaScript (melodía de Feliz Cumpleaños con Web Audio API, velas interactivas para soplar con clic o micrófono, partículas y confeti).
- `dist/`: Versión compilada (`index.html`, `styles.css`, `app.js`) lista para abrir con doble clic o arrastrar directamente a Netlify.

## Cómo usar con Astro
```bash
npm install
npm run dev
```
